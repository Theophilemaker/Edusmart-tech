# EduSmart – E-Learning and Digital Education Platform

**Driving in IT Skills**

EduSmart is a web-based e-learning platform designed to make education, digital skills, and learning resources more accessible to students, teachers, and technology enthusiasts. The platform provides a centralized environment where users can explore learning materials, access programming courses, discover educational services, and find digital products that support their learning journey.

Our mission is to empower learners with practical knowledge and IT skills through accessible, organized, and technology-driven education.

## 🚀 Project Overview

EduSmart aims to bridge the gap between learners and educational resources by providing a user-friendly platform for sharing and accessing knowledge online.

The platform focuses on web development, programming, databases, data science, and other technology-related subjects while supporting the continuous growth of digital skills.

## ✨ Key Features

- **📚 Online Courses:** Access educational content covering HTML, CSS, JavaScript, PHP, Java, Python, C++, Visual Basic, databases, and other subjects.
- **💻 Programming Tutorials:** Learn programming concepts through structured lessons and practical examples.
- **📂 Learning Resources:** Access and download available educational documents and learning materials.
- **🛠️ Educational Services:** Explore services designed to support students and technology learners.
- **🛍️ Digital Products:** Discover educational products and other technology-related resources.
- **🔐 Admin Management:** Manage learning sessions, uploaded resources, website content, and other supported administrative functions.
- **📱 Responsive Design:** Designed to provide a convenient experience across desktop computers, tablets, and mobile devices.
- **🌐 Accessible Learning:** Support independent learning by making educational resources available online.

*Note: Features may vary depending on the current implementation and deployment.*

## ⚙️ Installation and Setup

To run EduSmart locally, follow these steps.

### Prerequisites

- PHP-compatible local server, such as XAMPP or WAMP
- MySQL or MariaDB
- Web browser
- Git (optional)

### Step 1: Clone the Repository

```bash
git clone [https://github.com/Theophilemaker/Edusmart-tech.git]
```

Replace the placeholders with your actual GitHub username and repository name.

### Step 2: Move the Project

For XAMPP, place the project folder inside:

```text
C:\xampp\htdocs\edusmart
```

For WAMP, place it inside your WAMP `www` directory.

### Step 3: Configure the Database

1. Start Apache and MySQL.
2. Open phpMyAdmin.
3. Create a database for EduSmart.
4. Import the project's SQL file if one is included.
5. Update the database connection settings in the relevant PHP configuration file.

Never commit real database passwords, API keys, or other secret credentials to GitHub.

### Step 4: Run the Application

Open your browser and visit:

```text
http://localhost/edusmart/
```

Ensure that the project files and database configuration match your local setup.
